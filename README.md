# 🗺️ Mongloble

**Монгол Улсын аймаг, сумыг таах газарзүйн тоглоом.**

Нууц газрыг олоорой. Таны таасан газар нууц газраас хэр хол байгаагаас хамаарч өнгөтэй болно. Ойртох тусам улам халуун өнгөтэй болно 🔥

Дэлхийн улсуудаар тоглодог [Globle](https://globle-game.com) тоглоомоос санаа авч, Монголын газрын зураг дээр хийсэн.

👉 **Тоглох:** https://raqanova.github.io/mongloble

---

## Хэрхэн тоглох вэ?

1. **Аймаг** эсвэл **Сум** горимыг сонгоно.
2. Аймаг эсвэл сумын нэрийг бичээд **Таах** товчийг дарна.
3. Таасан газар газрын зураг дээр өнгөөр будагдана:
   - 🟨 Цайвар шар бол нууц газраас хол байна
   - 🟧 Улбар шар бол ойртож байна
   - 🟥 Бараан улаан бол маш ойрхон эсвэл хөрш байна
   - 🟩 Ногоон бол олчихлоо!
4. Таасан газрууд ойроосоо эрэмбэлэгдэн жагсаалтад гарна.

**Зөвлөгөө:** "Хөрш" гэж гарвал нууц газар яг тэр газартай хиллэдэг гэсэн үг.

## Горимууд

| Горим | Тоо | Хэцүү байдал |
|---|---|---|
| Аймаг | 21 аймаг + Улаанбаатар | ⭐ Хялбар |
| Сум | 330 сум | ⭐⭐⭐ Хэцүү |

Сумын горимд ижил нэртэй сумуудыг аймгаар нь ялгана. Жишээ нь `Булган (Ховд)`, `Булган (Архангай)`.

## Өөрийн компьютер дээр ажиллуулах

Ямар нэг програм суулгах шаардлагагүй.

1. Энэ repository-г татаж авна (**Code → Download ZIP**).
2. Задлаад `index.html` файлыг браузераар нээнэ.

## Файлын бүтэц

```
mongloble/
├── index.html   # Хуудасны бүтэц
├── style.css    # Загвар, өнгө
├── game.js      # Тоглоомын логик
└── data.js      # Аймаг, сумын хилийн өгөгдөл
```

## Хэрхэн ажилладаг вэ?

- **Газрын зураг:** Хилийн цэгүүдийн уртраг, өргөрөгийг энгийн проекцоор SVG зураг болгон зурна. Ямар нэг номын сан ашиглаагүй.
- **Зай:** Хоёр газрын хилийн хамгийн ойр цэгүүдийн хоорондох зайг [Haversine томьёо](https://en.wikipedia.org/wiki/Haversine_formula)-оор км-ээр тооцно. Хиллэдэг газрын зай 0 км гарна.
- **Өнгө:** Зайг HSL өнгө болгоно. 0 км бол улаан, 1200 км ба түүнээс дээш бол цайвар шар.

Бүх код цэвэр HTML, CSS, JavaScript дээр бичигдсэн. Кодын тайлбарууд монгол хэл дээр байгаа.
